# Contributing

TraceAML is pre-alpha. Small, reviewable changes with tests are preferred.

1. Create a branch from the current default branch.
2. Add or update tests for behavior changes.
3. Run the test and lint commands documented in `README.md`.
4. Explain compliance assumptions and data-handling impact in the change notes.

Do not add real customer, account, sanctions, or transaction data. Fixtures must
be synthetic and clearly labelled.

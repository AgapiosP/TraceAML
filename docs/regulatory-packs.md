# Regulatory packs

Regulatory packs are versioned context bundles, not executable legal opinions.
They identify the intended region, authorities, review topics, and source URLs.
Their dates and sources must be reviewed before a production release.

The v0.1 packs are deliberately conservative metadata stubs. They do not alter
detection thresholds. Later versions may map typologies, report terminology,
retention-policy identifiers, and required review steps, but changes must be
traceable and approved by an appropriately qualified reviewer.

The global engine never reports that an institution is “compliant.” It records
which pack and version informed an investigation so reviewers can reproduce the
context that was available at the time.
